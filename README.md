# zjones2142.github.io

Personal consulting site for Zach Jones — full-stack software developer.

Designed as a working instrument cluster: every gauge on the page is live,
measuring the visitor's scroll velocity, cursor speed, and activity in real
time. A tribute to the MU FSAE race-car dashboard project.

- **Stack:** hand-written HTML, CSS, and vanilla JavaScript. No frameworks,
  no build step, no dependencies.
- **Features:** SVG gauges with an ignition sweep on load, a canvas strip-chart
  of cursor/scroll velocity, a rolling odometer of cursor distance, a lap
  timer, a scroll-position track map, and scroll-triggered reveals.
- **A11y:** respects `prefers-reduced-motion`, keyboard-visible focus states,
  responsive down to mobile.

Live at [zjones2142.github.io](https://zjones2142.github.io).
